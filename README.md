# AdventureWorks Sales Dashboard - Power BI

## 📊 Project Overview
This project analyzes AdventureWorks sales data using Power BI to understand sales performance, profitability, product performance, and business trends.

## 🛠 Tools & Technologies
- Power BI
- DAX
- Data Modeling
- Data Visualization
- Data Analysis

## 📈 Key KPIs
- Total Sales
- Total Revenue
- Total Profit
- Profit %
- Average Order Value (AOV)
- Return Rate

## 🔍 Analysis
- Sales and revenue trends
- Category-wise performance
- Product performance
- Customer analysis
- Return analysis
- Time-based sales analysis

## 📁 Project File
`fact.pbix` contains the complete interactive Power BI dashboard.
